# Historique du projet

Le dépôt StepWatch fourni était initialement vide. La version 0.1.0 (3 novembre 2026) a fourni la première implémentation du cahier des charges ; elle ne constituait pas une correction vérifiée du logiciel historique 1.0.1, dont les sources n'étaient pas présentes.

La version 0.2.0 (7 novembre 2026) a intégré les correctifs et améliorations issus d'un audit fourni par l'utilisateur : capture et interface plus robustes, regroupement des doubles-clics, rapport autonome et diagnostic local. Le détail de cette intégration et ses mesures sont dans [AUDIT_INTEGRATION.md](AUDIT_INTEGRATION.md).

Les évolutions suivantes sont listées dans le [journal des modifications](../CHANGELOG.md).
